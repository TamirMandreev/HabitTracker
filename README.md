Название проекта: HabitTrecker (Трекер привычек)

Проект предназначен для помощи пользователям в формировании полезных привычек путем напоминаний и мотивации через уведомления в Telegram. Сервис позволяет создавать полезные привычки, ассоциированные с ними приятные награды и планировать регулярность выполнения привычек.

Установка: 
1. Открыть терминал и перейти в корень проекта 
2. Активировать виртуальное окружение: poetry shell 
3. Установить зависимости из pyproject.toml: poetry install 
4. Создать файл .env и указать в нем переменные окружения: 
   - SECRET_KEY
   Для работы с базой данных
   - NAME=
   - USER=
   - PASSWORD=
   - HOST=
   - PORT=
   Для работы с Telegram 
   - TELEGRAM_TOKEN=

Описание:

Основная модель — это привычка. Каждая привычка описывается следующим образом:

Я буду [действие] в [время] в [месте].

Основные поля модели "Привычка":

Пользователь: владелец привычки.
Место: место, где выполняется привычка.
Время: время выполнения привычки.
Действие: описание самой привычки.
Признак приятной привычки: признак, определяющий приятную привычку (булевое значение).
Связанная привычка: связанная привычка, выполняемая после полезной привычки.
Периодичность: частота выполнения привычки (например, ежедневно, раз в неделю и т.д.)
Вознаграждение: награда за выполнение полезной привычки.
Время на выполнение: продолжительность выполнения привычки (ограничивается двумя минутами).
Признак публичности: возможность публикации привычки другим пользователям.
Отличие полезной привычки от приятной и связанной
Полезная привычка: основное действие, которое пользователь хочет закрепить. Например, выход на пробежку.
Приятная привычка: приятное занятие, которым пользователь награждает себя после выполнения полезной привычки. Например, чашечка кофе после утренней зарядки.
Связанная привычка: вторая привычка, связанная с первой. Ее цель — облегчить закрепление главной привычки. Например, прогулка сопровождается прослушиванием любимой музыки.
Валидаторы
Нельзя одновременно выбрать связанную привычку и указать награду.
Время выполнения привычки ограничено двумя минутами.
Связанными могут стать только приятные привычки.
У приятной привычки не может быть своей награды или связи с другой привычкой.
Минимальная периодичность выполнения привычки — минимум раз в семь дней.
Пагинация
Списки привычек выводятся постранично с лимитом пять элементов на странице.

Права доступа
Каждый пользователь имеет полный доступ только к собственным привычкам (CRUD-операции).
Доступ ко всем публичным привычкам предоставляется без прав на их изменение или удаление.
Эндпоинты
Проект предусматривает следующие ключевые эндпоинты:

Регистрация пользователя.
Авторизация пользователя.
Список привычек текущего пользователя с поддержкой пагинации.
Список публичных привычек.
Создание, редактирование и удаление привычки.


Интеграция с Telegram
Для удобства пользователей предусмотрена интеграция с Telegram, позволяющая отправлять напоминания о предстоящих действиях.
